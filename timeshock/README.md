# QUIZ TIME SHOCK

飲食店の待ち時間に1〜2人でサクッと遊べる、平成・令和レトロ＆エモい世代別クイズゲームです。

## 🌟 特徴
- **世代別選択**: 1990年代、2000年代、2010年代から選択可能
- **3つのエモいジャンル**:
  - 🍩 エモい！平成・令和スイーツ＆フード
  - 🎤 青春のプレイリスト！懐かしのメガヒットソング
  - 🎮 あの頃夢中になった！マンガ・アニメ・ゲーム
- **TIME SHOCKタイマー**: 1問あたり10秒の制限時間でスリリングに展開
- **データ分離構成**: クイズ問題（270問）は `data/questions.json` から非同期ロード
