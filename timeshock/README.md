# 年代別 QUIZ TIME SHOCK!

懐かしのクイズ番組「タイムショック」風の画面演出で楽しめるWebクイズゲームです。

## 🌟 特徴
- **時計メーターUI**: 正解（緑）／不正解（赤）／現在地（黄）が視覚的にフィードバックされます。
- **1問10秒×12問構成**: 全120秒の制限時間でスリリングに挑戦。
- **3ジャンルからバランス出題**: 選択した年代（1990年代・2000年代・2010年代）から、以下3ジャンルそれぞれ各4問（計12問）がランダム抽出されます。
  1. 🍩 エモい！平成・令和スイーツ＆フード
  2. 🎤 青春のプレイリスト！懐かしのメガヒットソング
  3. 🎮 あの頃夢中になった！マンガ・アニメ・ゲーム
- **回転ペナルティ演出**: 正解数が3問以下の場合、画面が激しく揺れる「TIME SHOCK」演出が発生します。
